
# 🏥 AI-Powered Healthcare Data Insights and Dashboarding

## 📌 Project Overview
This project focuses on analyzing healthcare data using Microsoft Excel to generate meaningful insights into patient demographics, medical conditions, hospitalization details, and healthcare costs. An interactive dashboard helps present key metrics and supports data-driven decision-making.

## 🎯 Project Objectives
- Analyze patient demographics and medical examination records.
- Explore healthcare costs and hospitalization patterns.
- Examine BMI, HbA1c, heart issues, cancer history, and smoking status.
- Classify patients by weight status and other health indicators.
- Create an interactive dashboard to visualize key healthcare metrics.
- Transform raw healthcare data into meaningful insights.

## 🛠️ Tools and Technologies
- Microsoft Excel
- Excel formulas and functions
- XLOOKUP and data integration
- Data cleaning and transformation
- PivotTables and data analysis
- Dashboard design and data visualization

## 📂 Project Files
- `Excel Capstone Project - AI-Powered Healthcare Data Insights and Dashboarding.xlsx` — Main Excel workbook containing healthcare data, supporting worksheets, calculations, and dashboard.

## 📊 Key Performance Indicators (KPIs)
- Total number of patients
- Total healthcare costs
- Average healthcare charges
- Patient demographic distribution
- Medical condition patterns
- Weight-status distribution
- Hospitalization trends

## 🔍 Project Workflow
1. **Data Collection:** Organize patient, medical examination, and hospitalization datasets.
2. **Data Cleaning:** Standardize fields and check for missing or inconsistent values.
3. **Data Transformation:** Calculate and categorize relevant patient information.
4. **Data Integration:** Combine datasets using customer IDs and lookup functions.
5. **Data Analysis:** Explore healthcare expenses, demographics, and medical indicators.
6. **Dashboarding:** Present important metrics and summaries in Excel.

## 💡 Key Learnings
- Data cleaning and preprocessing
- Excel formulas and lookup functions
- Healthcare data integration
- Exploratory data analysis
- KPI development
- Dashboard creation
- Data visualization and storytelling

## 🚀 How to Use
1. Clone or download this repository.
2. Download the Excel workbook.
3. Open the workbook using Microsoft Excel.
4. Explore the worksheets to understand the data and calculations.
5. Navigate to the Dashboard worksheet to review the visualizations and summary metrics.

## 📈 Project Outcomes
